# rmdv v0.7.0 — deliberate refreshes and clearer Mindmaps

> Published 2026-08-14. Site deployed and live-verified 2026-08-14.
>
> Source: `main@9dd7217`; tag: `v0.7.0`.

rmdv v0.7.0 keeps long-lived reading workspaces current on demand and makes
large document Mindmaps easier to understand one level at a time. It also
improves desktop document opening, table layout, and Mindmap panel behavior.

## Highlights

### Refresh and path actions

- `⌘R` refreshes the current file and workspace folder without requiring a
  restart.
- Unsaved edits and documents changed during an async refresh are protected
  from stale disk results.
- Concurrent load/refresh results are ordered so an older operation cannot
  overwrite a newer navigation intent.
- `⌘⌥R` reveals the focused file in Finder, and `⌘⌥C` copies the focused file
  path.

### Document Mindmap depth folding

- In Document Mindmap, press `⌘K` followed by `0–6` to choose how many
  structural node levels remain visible; `0` expands all levels.
- The same seven actions appear in the command palette only while Document
  Mindmap is active.
- Markdown, JSON, YAML, and TOML Mindmaps share the behavior while retaining
  per-node Space folding.
- Structured-data folding avoids materializing hidden subtrees and preserves
  stable nodes when a collapsed frontier is expanded.

### Reading and desktop polish

- Markdown tables adapt to the reader width and use horizontal scrolling when
  their content needs more space.
- Document Mindmap panel sizing keeps a usable minimum width and its shortcuts
  act on the intended surface.
- macOS Finder document-open callbacks now reach the running app with the
  corrected native delegate encoding.
- The public site's AI disclosure sticker uses a lightweight static WebP while
  retaining its original footprint.

## Intentionally deferred

- Quick Slots (`MDV-017`) is not included.
- Theme Settings and Theme Studio (`MDV-019`) is not included.

Both remain isolated, uncommitted candidates requiring current-main porting and
their remaining native acceptance before a later release.

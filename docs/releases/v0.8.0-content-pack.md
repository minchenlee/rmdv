## Core message

**Every preference on one page. Your nine files one keystroke away.**

rmdv v0.8.0 adds a keyboard-driven Settings page, optional macOS window glass,
and per-workspace Quick Slots, and it is faster on large documents and
folders.

## User-facing copy

### Settings, in one place

Press `⌘,`. Pick a theme from its preview card, flip switches, and set font
size and window glass without leaving the keyboard. Every change is saved at
once.

### Glass, if you want it

On macOS, let the sidebar or the whole window show a soft blur of what is
behind it, at 60–90% opacity.

### Nine files, one keystroke

`⌘N` puts the current file in a Quick Slot; `⌘1`–`⌘9` bring it back, in the
same view mode you left it in.

## Core message

**Refresh deliberately. Fold structure to the depth you need.**

rmdv v0.7.0 gives keyboard-first readers an explicit way to reload the current
file/workspace and a consistent depth control for Markdown and structured-data
Document Mindmaps.

## User-facing copy

### Keep the workspace current

Use `⌘R` to refresh the current file and folder. rmdv preserves unsaved edits,
rejects stale async results, and reports whether the file, folder, both, or
neither were refreshed. Use `⌘⌥R` to reveal the focused file in Finder and
`⌘⌥C` to copy its path.

### Read Mindmaps one depth at a time

While Document Mindmap is active, press `⌘K` and then `1–6` to keep that many
structural levels visible, or `0` to restore the complete graph. The command
palette exposes the same actions for Markdown, JSON, YAML, and TOML documents.

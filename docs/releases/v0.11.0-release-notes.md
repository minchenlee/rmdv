## What's New in v0.11.0

rmdv now works as well with a mouse or trackpad as it does with the keyboard. Mermaid diagrams look closer to the real Mermaid, and you can choose how wide the text column is.

### ✨ New Features

- **Toolbar** (MDV-048): A toolbar at the top has the sidebar toggle, the file name, Read / Edit / Mind Map, Save, Find, the Command Palette and Settings. Every button has a tooltip. In Settings you can show it always (the default) or only when the pointer is near the top.
- **Back and Forward** (MDV-048): rmdv remembers the files you open and the links you follow inside a document, like a browser. Use the mouse side buttons, ⌘[ and ⌘], the toolbar arrows, or a two-finger swipe on macOS. Each stop keeps its reading position.
- **Right-click menus** (MDV-048): Right-click files, text, links, images, code, mind map nodes, outline items and search results. In the file tree you can create, rename and move files to the Trash, copy paths, and add a file to a Quick Slot.
- **Links** (MDV-048): Point at a link to see where it goes. Links to local files open in rmdv. ⌘-click opens a web link in the background. Linked images, such as badges, are clickable.
- **Mind map with the pointer** (MDV-048): Click a node to select it, and drag to pan. Double-click a heading to open it in the reader, or a file in Full Mindmap to open it. A new setting makes scrolling pan instead of zoom.
- **Gestures** (MDV-048): A new image and diagram viewer zooms toward the pointer, pans, and supports pinch. Pinch or ⌘-scroll in the reader changes the font size. Trackpad scrolling in the editor follows your fingers.
- **Better text selection** (MDV-048): You can start a selection in the margins. Dragging past the top or bottom edge scrolls the document. Double-clicking Chinese or Japanese text selects a word on macOS. Shift-click extends a selection across blocks.
- **Reading width** (#84): Choose Narrow, Default, Wide or Full in Settings → Reading, or press ⌘⌥[ and ⌘⌥]. The width grows with the font size, so a line keeps the same number of characters when you zoom.
- **New Mermaid renderer** (#82): Mermaid diagrams are drawn by Merman. Their layout and look are closer to the official Mermaid, including flowcharts with Chinese or Japanese labels.
- **Sidebar** (MDV-048): When the sidebar is hidden, move the pointer to the left edge of the window to show it until the pointer leaves. Drag the divider to resize the sidebar; the width is saved. The outline highlights the section you are reading.
- **macOS menu bar** (MDV-048): rmdv has a full native menu bar (File with Open Recent, Edit, View, Go with Quick Slots, Window, Help). rmdv also remembers the window size and position.
- **Global Quick Slots** (MDV-048): The 9 Quick Slots are shared by all workspaces. A slot in another folder opens that folder.
- **Safe close** (MDV-048): Closing the window, ⌘Q, `rmdv close` and Install Update ask before they drop unsaved edits. The window title shows `•` while a file has unsaved edits.
- **Smaller touches** (MDV-048): Drag the empty toolbar area to move the window, and double-click it to zoom. Copy buttons on code, math and diagrams show on hover. Click the footer to change the statistic it shows. Rows in the shortcut sheet run their action on click. Wide tables show a shade on the side that overflows.

### 🐛 Bug Fixes

- **Clicks in overlays** (MDV-048): A click on empty space in a panel no longer closes it. A pointer that does not move no longer takes the selection from the arrow keys.
- **File finder** (MDV-048): The keyboard selection stays in the visible rows. A "N more" line shows how many results are hidden.
- **Image alt text** (MDV-048): Alt text is no longer drawn as a paragraph under an image. It still shows while the image loads or fails.

### ⚠️ Known Limits

- Building from source now needs Rust 1.95 or newer (#82).
- Move to Trash works only on macOS. Other platforms show a message.
- The editor does not auto-scroll when you drag a selection past its edge.
- You cannot drag a file from rmdv to Finder.
